Dependabot Security Fixes — October 2026

Scope: GitHub Dependabot alerts for Sphere/eagle-fusion · Date: 2026-10-26 · Branch: fix/dependabot-vulnerabilities (cut from master @ bd7c14153)

Summary

GitHub reported 306 open security alerts on this repository. All of them came from third-party packages recorded in yarn.lock, not from our own code. This change upgrades, pins or removes those packages so that 289 of the 306 alerts are resolved, including all 17 critical ones. The remaining 17 sit inside one Sunbird library we do not control and cannot be fixed from this repo.

No application source code was changed. No .ts, .html or .scss file is touched. The change is limited to dependency versions (package.json, yarn.lock) and the removal of one unused global script from angular.json. The unit tests, the production build and the production prerender (the step the Docker image runs) all pass.

3. Nested packages forced to patched versions

The lockfile was refreshed so that indirect dependencies move to their latest compatible patch releases. Where a parent package pins an old version, a scoped resolutions entry forces the patched one. Each entry targets one parent only, so nothing else is affected:

undici, vite, ip-address, ws, qs, form-data, tough-cookie, moment (under vis-util), uuid (under sockjs and gzipper), postcss-selector-parser (under Tailwind) and @modelcontextprotocol/sdk.

Most of these are build-time tools (Angular CLI, webpack dev server, Tailwind, Jest) that never reach the browser.

Watch-outs

Do not upgrade @angular-devkit/build-angular or @angular/cli to 21.2.28. That release moves webpack from 5.105 to 5.112, which keeps type-only imports (SimpleChanges, HttpEvent, Signal, ModuleWithProviders) in the output and fails the build with 18 "export not found" errors. 21.2.27 has all the security fixes and builds cleanly. The versions are pinned exactly (no ^) on purpose. Ignore Dependabot PRs that bump them until this is resolved, either by a later Angular release or by switching those imports to import type.

The Docker image still runs yarn add @angular/localize@21 and yarn add moment vis-util after install. These steps existed before this change and are unchanged, but they resolve versions outside the lockfile at image build time.

Manual check before release

  1. Open any course with a PDF resource and confirm the toolbar, zoom and page rendering look as before (because of the pdf_viewer.css 3.4 → 5.4 change).
  2. Smoke-test login and signup, and open one course's Discussion tab.
  3. Load /public/home with JavaScript disabled to confirm the prerendered HTML is served.

Rollback

All changes are confined to package.json, yarn.lock and angular.json. Rolling back means reverting the merge commit, or redeploying the previous release-X.Y.Z branch.
